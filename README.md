# 🌱 Sistem Informasi Pembagian Pupuk Kepada Petani

Sistem Informasi Pembagian Pupuk Kepada Petani merupakan aplikasi berbasis web yang dikembangkan untuk membantu proses pengelolaan data petani, lahan pertanian, jenis tanaman, kebutuhan pupuk, serta pencatatan distribusi pupuk.

Aplikasi ini bertujuan untuk mempermudah pengelolaan informasi dan administrasi pembagian pupuk kepada petani secara terstruktur.

## ✨ Fitur Utama

### 1. Dashboard
- Menampilkan ringkasan informasi sistem.
- Informasi data petani dan distribusi pupuk.

### 2. Manajemen Data Petani
- Pengelolaan data petani.
- Penambahan, pengubahan, dan penghapusan data petani.

### 3. Manajemen Lahan
- Pengelolaan data lahan pertanian.
- Pencatatan informasi lahan milik petani.

### 4. Manajemen Tanaman
- Pengelolaan jenis tanaman.
- Pencatatan data tanaman pertanian.

### 5. Manajemen Pupuk
- Pengelolaan data pupuk.
- Informasi jenis pupuk yang tersedia.

### 6. Kebutuhan Pupuk
- Pengelolaan data kebutuhan pupuk.
- Pencatatan kebutuhan pupuk berdasarkan data pertanian.

### 7. Distribusi Pupuk
- Pencatatan distribusi pupuk kepada petani.
- Pengelolaan data penyaluran pupuk.

### 8. Manajemen Pengguna
- Pengelolaan data pengguna sistem.
- Fasilitas autentikasi dan login.

## 🛠️ Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## 🎯 Tujuan Pengembangan

Membantu proses administrasi pembagian pupuk kepada petani melalui sistem terkomputerisasi, sehingga pengelolaan data pertanian, perhitungan kebutuhan pupuk, dan pencatatan distribusi dapat dilakukan secara lebih terstruktur.
